# 유사기업(피어) 선정·추천 기준 — v2 (2026-08-28 확정, 앱 반영)

작성 2026-08-28. 근거: ① 실무 Valuation 보고자료의 4단계 선정 기준(모집단 → 사업 → 재무 → 경영상), ② 기존 유사기업 검토 조서의 키워드 스크리닝·제외 사유 방식, ③ WACC 베타 산출 목적에서 추가로 필요한 기준(제안). 각 항목에 **[자동]**(앱이 KIND·DART·KRX로 판정) / **[반자동]**(피어 자료 로드 후 플래그) / **[수동]**(사람 판단) 표시.

---

## 0. 원칙

- 추천은 **후보를 줄여주는 것**이지 결정이 아니다. 최종 선정과 제외 사유는 사람이 쓰고, 엑셀 `후보군` 시트에 남긴다(조서 감사 추적).
- 기준은 **정성(사업) → 정량(재무) → 경영상** 순서로 좁힌다(보고자료 순서 그대로).
- WACC 베타 용도는 멀티플(EV/EBITDA) 용도와 조건이 다르다: 멀티플은 이익 흑자가 필수지만, 베타는 **주가 시계열 품질**(상장 기간·유동성)이 핵심. 두 용도를 나눠 둔다.

## 6. 확정 (2026-08-28)

- **전부 감점제(soft)**. 하드 제외는 스팩·임시코드뿐. 감사의견·영업적자·관리종목 등은 **플래그만** 붙이고 집계 포함 여부는 사람이 결정.
- 상장 경과: **2년(104주) 기준 유지** (2년 미만 −5).
- 시총: 고정 하한 없음 — 케이스별로 시총 필터 입력. **대상 시총(억)** 을 넣으면 0.2x~5x 범위 +2.
- EBITDA: 점수에 넣지 않음. 대신 최근 FY **영업이익 < 0 이면 '영업적자' 플래그**(요약 탭·피어 시트).
- 12월 결산 아님: −1 (감점).
- 제외 키워드 기본 세트: `스팩, 인수합병, 지주, 홀딩스, 유통, 도매, 임대, 리츠` (후보군 탭에서 편집) — 사명·업종·주요제품에 있으면 −5/개.
- KSIC: 대상 코드 자동(앞4자리 +2, 앞3자리 +1) + **코드군 직접 입력칸**. 코드군을 넣으면 키워드 없이도 후보에 포함.
- 감사의견: DART 최근 FY 의견이 '적정'이 아니면 플래그 `감사의견:xxx`.
- 추천 개수: 5개 고정 (점수 > 0).
- 미구현(후속): 관리종목·거래정지 자동 제외(KRX), 순현금 과다 플래그 수치, EV 하한.
